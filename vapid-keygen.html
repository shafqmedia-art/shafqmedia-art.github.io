مولّد المفاتيح السرية

هالصفحة بتشتغل على جهازك بس، وما بتبعت ولا شي للإنترنت. المفتاح السري ما بيطلع من جهازك.

لا تصوّر هالشاشة، ولا تحفظ المفاتيح بملف جنب ملفات الموقع، ولا تبعتها لحدا (ولا لـ Claude). انسخها لمكانها وسكّر الصفحة.
  1. Supabase ← Edge Functions ← Secrets: بدّل VAPID_PUBLIC وVAPID_PRIVATE، وضيف CRON_SECRET.
  2. GitHub ← shafq-app ← config.js ← بدّل قيمة pushKey بالمفتاح العام الجديد، وزيد رقم الكاش بـ sw.js.
  3. Supabase ← SQL Editor: شغّل cron.sql بعد ما تحط فيه CRON_SECRET، وبعدها delete from public.push_subs;
  4. كل واحد بالفريق يفتح النظام ويفعّل الإشعارات من جديد.
