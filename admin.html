لوحة التحكم

من هون بتعدّل الموقع، بتضيف أعمال وصور وفيديوهات، وبتنشرها بكبسة.

أول مرة؟ اعمل مفتاح الدخول هيك:
  1. افتح صفحة إنشاء Token
  2. Token name: shafq-admin — Expiration: اختار مدة طويلة
  3. Repository access: Only select repositories واختار shafqmedia-art.github.io
  4. Permissions ← Repository permissions ← Contents: Read and write
  5. اكبس Generate token، انسخه وحطه هون

المفتاح بينحفظ على هالجهاز بس. لا تعطيه لحدا.
