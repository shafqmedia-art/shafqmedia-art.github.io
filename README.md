# شفق بوت

منصة **شفق ميديا** لإدارة صفحات فيسبوك وحسابات إنستغرام. بتشتغل كتطبيق على **الجوال والآيفون واللابتوب**، وفيها:
- **موقع عام** فيه صفحة تعريفية وجدول الباقات وتسجيل الزباين.
- **لوحة للزباين** بحسب باقة كل واحد.
- **لوحة إلك** كمدير للمنصة.

## المنصة والباقات (نسخة 3)

| الجزء | شو فيه |
|---|---|
| **الموقع العام** | `/` صفحة تعريفية (إدارة صفحاتك صارت أسهل + المزايا الخمسة + جدول الباقات)، `/pricing` جدول المزايا والأسعار، `/signup` تسجيل زبون مع تجربة مجانية |
| **الباقات** | **شفق لايت** (ردود نصية)، **شفق برو** (الأكثر طلباً)، **شفق ماكس** (كل شي + متجر + مساعد ذكي + تقارير تفصيلية). كل باقة إلها أسعار شهر / 3 / 6 / سنوي، لفيسبوك أو لفيسبوك + إنستغرام. **الأسعار فاضية لحتى تحطها من لوحة المنصة** |
| **الاشتراك** | الزبون بيختار الباقة والمدة والمنصات، بيحط كوبون إذا عنده، وبيرفع رقم العملية أو صورة الإشعار. إنت بتقبل الطلب، والباقة بتتفعّل لحالها والمدة بتنضاف |
| **القفل حسب الباقة** | كل قسم أو خيار مو ضمن باقة الزبون بيطلعله مع زر ترقية. البوت كمان بيحترم الباقة: لايت بيبعت نص بس، والستوري والمتجر والمساعد حسب الباقة. وإذا انتهى الاشتراك، البوت بيوقف والزبون بيتحوّل لصفحة الاشتراك |
| **لوحة المنصة** (`/admin`) | نظرة عامة (زباين، فعّال، تجربة، منتهي، دخل)، الزباين (تغيير الباقة، المدة، صفحات إضافية، رصيد AI، إيقاف، +30 يوم، **دخول كزبون**، حذف)، طلبات الاشتراك مع صورة الإشعار (قبول / رفض)، **الباقات والأسعار** (مزايا كل باقة بالتشيك بوكس + جدول أسعار)، الكوبونات، والإعدادات (التسجيل، أيام التجربة، تعليمات الدفع، العملة، مفاتيح الذكاء) |
| **شفق AI** | توليد منشورات وكابشنات، ردود على التعليقات (كمان زر "توليد بالذكاء" بفورم الرد)، توليد صور، **مساعد ذكي** بيرد على الدايركت من معلومات الصفحة. الرصيد شهري حسب الباقة |
| **إدارة المحتوى** | نشر فوري أو مجدول: فيسبوك (نص، صورة، فيديو) وإنستغرام (صورة، **ريلز**) |
| **فلترة الكلمات النابية** | إخفاء أو حذف التعليقات المسيئة تلقائياً |
| **التقارير** | إحصائيات عامة، تفصيل لكل منشور، مبيعات المتجر، سجل الحوادث والتنبيهات، وتصدير CSV للنشاط والطلبيات |

## الميزات

| الميزة | شو فيها |
|---|---|
| **الرد التلقائي** | قواعد على التعليقات والدايركت، لمنشور محدد أو كل المنشورات، أو تعمل منشور جديد (مع صورة وجدولة) من التطبيق. كلمات مفتاحية، رد علني بكذا صيغة مع زر "اقترح صيغ"، ورسالة خاصة (نص أو رسالة تفاعلية فيها صور وأزرار). خيارات: بحاجة لمنشن، إضافة عبارة الرد للرسالة، إعجاب تلقائي، الرد بس للي عامل إعجاب، الرد على التعليقات المتكررة. الحالة: فعّال / غير فعّال / ضمن فترة. نسخ، حذف، إيقاف الكل، وزر "جرّب البوت" |
| **الرد على الرسائل** | رد افتراضي على الدايركت والرد على الستوري (مع كلمات مفتاحية اختيارية) + رسالة ترحيب |
| **متجر شفق** | 4 قوالب (متجر، خدمات، مطعم، حجوزات)، تصنيفات بتصنيفات فرعية وسعر موحّد، منتجات بأصناف فرعية ومعرض صور، استيراد وتصدير CSV، ترتيب بالسحب، سلة وطلبيات جوّا الماسنجر، وتغيير حالة الطلب مع إشعار للزبون |
| **الحملات** | رسائل جماعية للكل أو للي تفاعلوا مع منشور، تاغ الإرسال، الإشعار، إرسال فوري أو مجدول، لصفحة وحدة أو كذا صفحة، وقائمة باللي استلموا |
| **بوت المحادثة** | مجموعات وبلوكات (نص، صورة، معرض، فيديو، ملف) وأزرار (وحدة، رابط، اتصال، واتساب، المتجر)، رسالة الترحيب، زر "ابدأ"، والقائمة الثابتة الثابتة مع زر "تحديث القائمة" |
| **الإدارة** | دخول باسم مستخدم وكلمة سر، فريق (مدير / محرر)، تغيير كلمة السر (بيطلّع باقي الأجهزة)، إحصائيات آخر أسبوعين، المستخدمين، التقارير والسجل |
| **التطبيق** | PWA: بيتثبّت من المتصفح على أندرويد وآيفون واللابتوب، وبيتحدّث لحاله |

Node.js 20+ **بدون أي مكتبات خارجية**. البيانات بملف `data/db.json`، والصور المرفوعة بـ `data/uploads/`.

## 1. التجربة على جهازك

```bash
cp .env.example .env      # وعبّي القيم
npm start                 # بيفتح على http://localhost:3000
npm test                  # اختبار مطابقة الكلمات
```

أول ما يشتغل السيرفر بيعمل شغلتين:
- حساب **"شفق ميديا"**، وكل شي فيه مفتوح بلا باقة.
- حساب **مدير المنصة** من `ADMIN_USERNAME` و `ADMIN_PASSWORD`.

بعدها:
1. فوت على **لوحة المنصة ← الباقات والأسعار**، وحط الأسعار لما تقرر.
2. من **الإعدادات** حط تعليمات الدفع ومفتاح الذكاء.
3. ابعت للزباين رابط الموقع. هنن بيسجّلوا لحالهم، وبيبلّشوا بالتجربة.

## 3. الاستضافة (لازم فيها تخزين دائم)

### Railway (الأسهل)
1. railway.app ← New Project ← Deploy from GitHub ← `shafq-bot`.
2. ضيف **Volume** والـ Mount Path: `/data`.
3. بـ Variables حط متغيرات البيئة تحت، و`DATA_DIR=/data`.
4. Settings ← Networking ← Generate Domain. هاد الرابط هو `BASE_URL`.

### أو Render
Web Service مع **Disk** (Mount Path `/data`) على خطة مدفوعة. الخطة المجانية بتمسح البيانات وبتنام، فالـ Webhook والرسائل المجدولة ما رح يشتغلوا.

| المتغير | شو هو |
|---|---|
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | حساب المدير الأول |
| `SESSION_SECRET` | نص عشوائي طويل (40 حرف أو أكتر) |
| `META_APP_ID` / `META_APP_SECRET` | من تطبيق Meta Developers |
| `META_VERIFY_TOKEN` | أي كلمة، وبتحط نفسها بإعدادات الـ Webhook |
| `BASE_URL` | رابط الموقع (https)، بدون `/` بالآخر |
| `DATA_DIR` | مكان حفظ البيانات (مثلاً `/data`) |
| `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` | اختياري، فيك تحطهم من لوحة المنصة ← الإعدادات |

### مفاتيح الذكاء الاصطناعي
- **Claude** (للنصوص والمساعد الذكي): من console.anthropic.com ← API Keys.
- **OpenAI** (لتوليد الصور، أو للنصوص إذا اخترته): من platform.openai.com ← API keys.
- الشركتين بيحاسبوا حسب الاستعمال، فحدّد رصيد AI بكل باقة بشكل يغطي كلفتك.

## 4. تثبيت التطبيق

بعد الرفع افتح الرابط، وبعدين:
- **أندرويد:** من Chrome، القائمة ⋮ ← **تثبيت التطبيق**.
- **آيفون:** من **Safari**، زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **لابتوب:** من Chrome أو Edge، أيقونة التثبيت ⊕ بشريط العنوان.

في صفحة **تثبيت التطبيق** جوّا البوت فيها نفس الشرح وزر تثبيت مباشر. التطبيق بيتحدّث لحاله كل ما ترفع نسخة جديدة.

## 5. إعداد تطبيق Meta

1. developers.facebook.com ← **Create App** ← نوع **Business**.
2. ضيف: **Facebook Login for Business**، **Messenger**، **Instagram** (API setup with Facebook login)، **Webhooks**.
3. **App settings ← Basic**:
   - Privacy Policy URL: `BASE_URL/privacy`
   - Data deletion instructions URL: `BASE_URL/data-deletion`
4. **Facebook Login ← Valid OAuth Redirect URIs**: `BASE_URL/oauth/callback`
5. **Webhooks** (Callback `BASE_URL/webhook` + Verify token):
   - **Page:** `messages`، `messaging_postbacks`، `messaging_referrals`، `feed`
   - **Instagram:** `messages`، `messaging_postbacks`، `comments`
6. الصلاحيات اللي بيطلبها البوت: `pages_show_list, pages_messaging, pages_manage_metadata, pages_read_engagement, pages_manage_engagement, pages_manage_posts, pages_read_user_content, business_management, instagram_basic, instagram_manage_messages, instagram_manage_comments, instagram_content_publish`
7. لحتى يقدر **زباينك** يربطوا صفحاتهم، لازم تطبيق Meta يكون **Live**، ومعمول **App Review** لكل هالصلاحيات، و**Business Verification**. قبل هيك، بس الحسابات اللي إلها دور بالتطبيق بتقدر تربط.
8. ارجع للتطبيق ← **الحسابات المربوطة** ← **ربط حساب**.

## 6. شو لازم تعرف

- حساب الإنستغرام لازم يكون **احترافي** ومربوط بصفحة فيسبوك، ولازم تفعّل من إعداداته **السماح بالوصول للرسائل**.
- طالما تطبيق Meta بوضع **التطوير**، بيشتغل بس على الحسابات اللي إلها دور فيه. لحسابات الزباين لازم **App Review** و**توثيق النشاط التجاري**. تأكد إنه التسجيل بيمشي معك من سوريا، وممكن تحتاج بيانات شركة من السعودية.
- قوانين Meta:
  - الرد على تعليق: رسالة خاصة **وحدة** خلال **7 أيام**، فالبوت بيبعت أول جزء من الرسالة بس.
  - الدايركت: خلال **24 ساعة** من آخر رسالة من الشخص.
  - الرسائل الجماعية للي مضى عليهم أكتر من 24 ساعة بتنبعت مع **تاغ**. لا تستعمل التاغات للإعلانات، وخلّيها رسالة وحدة بالأسبوع.
- بعض الميزات **لفيسبوك بس**، لأنه API إنستغرام ما بيدعمها:
  - إنشاء منشور من التطبيق
  - الإعجاب التلقائي، والرد بس للي عامل إعجاب
  - رسالة الترحيب وزر "ابدأ"
  - زر الاتصال (بالإنستغرام بيبعت الرقم كرسالة)
- القائمة الثابتة بتنشر أزرار من نوع وحدة أو رابط. Meta لغت القوائم الفرعية.
- الدفع بالمتجر بيصير خارج البوت (تحويل أو عند الاستلام). البوت بيسجّل الطلب وبيبعت تأكيد للزبون.

## هيكل المشروع

```
server.js            السيرفر، الدخول، الـ Webhook
lib/db.js            التخزين (JSON)
lib/auth.js          المستخدمين وكلمات السر والجلسات
lib/http.js          الكوكيز، الفورمات، رفع الملفات، الراوتر
lib/meta.js          Graph API v21.0
lib/messages.js      تحويل الرسائل (نص/صورة/معرض/أزرار) لصيغة Meta
lib/webhook.js       الدايركت، الأزرار، التعليقات، الستوري
lib/store.js         المتجر جوّا الماسنجر (تصنيفات ← منتجات ← سلة ← طلب)
lib/broadcast.js     الحملات والمجدول
lib/rules.js         مطابقة الكلمات (مع توحيد العربي)
lib/plans.js         الباقات والمزايا وحالة اشتراك كل زبون
lib/ai.js            شفق AI (Claude / OpenAI)
lib/content.js       نشر وجدولة المنشورات والريلز
routes/              صفحات كل ميزة
views/               واجهات كل ميزة
public/              الستايل، السكربت، الأيقونات، manifest، sw.js
```
